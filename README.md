# Java OOPS Practice

A collection of foundational Java Object-Oriented Programming (OOP) practice problems and lab exercises for beginners.

---

## 📂 Programs Included

### 1. `MultiplyTest.java` (Method Overloading)
Demonstrates **Method Overloading** by defining multiple `multiply()` methods with different parameter types:
- `multiply(int, int)`: Multiplies two integers and prints the product.
- `multiply(String, int)`: Repeats the given string a specified number of times.
- `multiply(Complex, Complex)`: Multiplies two complex numbers `(a + bi) * (c + di)`.
- `multiply(Point, int)`: Translates/scales a 2D coordinate point `(x, y)` by a factor.

### 2. `CircleTest.java` (Classes & Constructors)
Demonstrates classes, constructors (default and parameterized), and method calculation:
- Computes circle **Area** ($πr^2$) and **Circumference** ($2πr$).
- Displays formatted circle details.

### 3. `complexno.java` (Objects & Methods)
Demonstrates object manipulation and complex number addition:
- Adds real and imaginary parts of two complex number objects.

---

## 🚀 How to Run

1. Open the project in **Eclipse IDE** (or any Java IDE).
2. Navigate to `src/q4/`.
3. Right-click on any test file (e.g. `MultiplyTest.java`) $\rightarrow$ **Run As** $\rightarrow$ **Java Application**.
