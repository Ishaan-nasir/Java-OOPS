# Java OOPS Practice

A repository containing Java Object-Oriented Programming (OOP) practice questions, lab assignments, and core concept demonstrations.

---

## 📌 Topics Covered

- Classes and Objects
- Constructors (Default & Parameterized)
- Method Overloading and Method Overriding
- Encapsulation, Inheritance, and Polymorphism
- Practical Problem Solving in Java

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Ishaan-nasir/Java-OOPS.git
   ```
2. Open the project in your preferred IDE (e.g., **Eclipse**, **IntelliJ IDEA**, or **VS Code**).
3. Navigate to the `src/` directory and run any Java file as an application.
